# 智能客服控制台（React 18）

与旧版 `app/static/dashboard.html`（`/dashboard`）**并存**，互不替代。

| 前端 | 地址 | 说明 |
|------|------|------|
| 旧版 HTML | `http://127.0.0.1:8000/dashboard` | 原单页控制台 |
| React（开发） | `http://127.0.0.1:5173` | `npm run dev` |
| React（生产） | `http://127.0.0.1:8000/console/` | 先 `npm run build`，由 FastAPI 托管 |

页面右上角可互相跳转。

## 技术栈

- React 18
- TypeScript
- Vite 5

## 流式交互

- 通过 POST Fetch 读取 SSE，支持标准运行事件与旧版事件名。
- 未收到完成事件就断流、事件解析失败或服务端执行失败时，保留部分回答并显示中断原因。
- 等待响应头或连续无数据超过 120 秒时断开连接；不自动重发，避免重复执行工具。
- 切换/新建会话保留原 SSE 连接，各会话独立接收并缓存消息、执行阶段和来源；切回时显示最新结果并继续流式更新，可在其他会话发送问题。
- “停止接收”或“清空聊天”只中断当前会话请求；切换身份或页面卸载时清理所有请求。旧事件和旧历史响应不会覆盖新的会话状态。
- 后台接收依赖当前页面保持打开，刷新/关闭页面不会恢复流式连接；已加载或生成的会话内容保存在页面内存中。
- 停止接收只中断前端连接，不保证远端模型或工具立即停止。
- 运行 `npm test` 验证 SSE 分块、结束、失败和取消处理；`npm run build` 检查类型并构建。

## 启动

```bash
# 后端 :8000
# 前端开发
cd frontend
npm install
npm run dev
```

## 构建并由后端托管

```bash
cd frontend
npm run build
# 然后访问 http://127.0.0.1:8000/console/
```
